# Optional CapCut workflow — one consumer of the wider Creator Asset Library

This is an optional CapCut-specific workflow. The wider creative source directory is editor-agnostic and supports many art directions, including custom graphics and audio. Use this sequence for Shorts/Reels/TikTok built from original gameplay and creator footage:

1. **Start with original footage.** Create a 9:16 project for vertical output; keep the original gameplay clip readable and preserve meaningful action at center.
2. **Choose only purposeful insert footage.** Import a Pexels/Mixkit *Free License* vertical clip or similar source as B-roll if it genuinely explains the story. Don't cover a short with filler just to add motion.
3. **Use clean transitions.** Match a cut to a Mixkit transition sound, then add an MP4 film/light leak briefly if it improves continuity. A stock *video template project file* for Premiere is not a CapCut project.
4. **Layer effects.** Import Kenney transparent sprites, PNG callout icons, or Mixkit overlay footage on tracks above the base clip. For green-screen files use CapCut's chroma key, then trim tightly.
5. **Use external, independently licensed audio.** Put SFX and a clearly permitted background track on the CapCut audio timeline; duck under speech/game audio. Avoid exporting captured copyrighted stream music.
6. **Make graphics legible.** Use a few consistent font families, readable contrast, simple icons and restrained backgrounds. Convert SVG icons to transparent PNG with Photopea if needed.
7. **Check exports per platform.** Watch the final video with sound, inspect transitions and text on a phone-sized preview, then verify any external audio licensing covers each intended platform. Save the original download/terms links with the project.

## Example source combinations

- **Gameplay victory or reveal:** [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds) + [Kenney Input Prompts](https://kenney.nl/assets/input-prompts) + [Mixkit transition swoosh](https://mixkit.co/free-sound-effects/transition/).
- **Quick tutorial:** [Lucide icons](https://lucide.dev/icons/) exported to PNG + [Pexels vertical video](https://www.pexels.com/search/videos/vertical/) for genuine cutaways + existing CC0 sound catalog for UI emphasis.
- **High-energy edit:** [Mixkit light leaks](https://mixkit.co/free-stock-video/light-leaks/) + [Kenney Particle Pack](https://kenney.nl/assets/particle-pack) + permitted [Mixkit background music](https://mixkit.co/free-stock-music/). Select *Free License* video items.
- **Thumbnail/cover:** [Pexels photos](https://www.pexels.com/) + [Poly Haven textures](https://polyhaven.com/textures) + licensed [Google Fonts](https://fonts.google.com/) + [Photopea](https://www.photopea.com/) for cutouts.

## Licensing quick check

- Match the license of the **exact downloaded file**, not a site's general marketing wording.
- Prefer CC0 for reusable source effects. For stock services, use media in a transformed video, never as an independent asset pack.
- Review depiction of real persons, brands, copyrighted characters, and trademarked game UI separately.
- For cross-posting, do not assume a license restricted to YouTube or CapCut/TikTok grants rights elsewhere.
- Music rights and automated Content ID claims are separate questions. Keep dated terms and track metadata.
- Final QA is visual and audible; the existence of downloaded files or a successful export doesn't prove clean playback.
